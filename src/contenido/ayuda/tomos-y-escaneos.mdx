## Ver los folios de un tomo

1. En el menú lateral, abra **Tomos**.
2. Si usted es Admin País o Admin Regional, elija la **Escuela**. Cada escuela tiene sus propios tomos y folios. Los demás roles ven siempre su escuela.
3. Elija uno de los **tomos con folios** que aparecen para esa escuela. El sistema abre el primero automáticamente.
4. Use las flechas para pasar de un folio al siguiente. Se indica "Folio X de Y".

Si la escuela no tiene imágenes, el sistema muestra **Sin tomos digitalizados**.

## Subir un folio nuevo

En la sección **Subir nuevo folio**:

1. Si es Admin País o Admin Regional, elija la **Escuela**.
2. Escriba el **N° de tomo** y el **N° de folio**.
3. Presione el recuadro punteado y seleccione la imagen o el archivo desde su equipo.
4. Presione **Subir folio**.

Al terminar, el folio aparece en el tomo correspondiente.

| Dato | Detalle |
|---|---|
| Formatos permitidos | JPG, JPEG, PNG y PDF |
| Quién puede subir | Admin País, Admin Regional, Admin Escuela y Staff, dentro de su alcance |

> **Tenga en cuenta:** el botón **Subir folio** se habilita cuando están completos el tomo, el folio y el archivo. Si el sistema indica que el formato no es permitido, convierta el archivo a uno de los formatos de la tabla. Cada subida queda registrada en la auditoría.
